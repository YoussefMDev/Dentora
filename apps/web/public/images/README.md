# Dentora demo image assets

These locally stored WebP images are stock photographs used only as visual examples. They show empty dental rooms or equipment and do not represent verified Dentora premises, equipment, services, or outcomes. No patient imagery is included.

The photos are published under the standard [Unsplash License](https://unsplash.com/license), which permits free commercial and non-commercial use. The image pages identified each photo as free under that license when selected. Each file was downloaded in WebP format at a reduced display width for this project.
